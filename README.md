# صوت البلاد — جريدة الأخبار الجزائرية

> جريدة إلكترونية جزائرية بطابع صحفي كلاسيكي أصيل: تجميع آلي للعناوين والملخصات من المصادر الوطنية، مع الربط المباشر بالمصدر الأصلي لكل خبر.
>
> **الإصدار الحالي: V1.4.2** — جلب ذاتي بشريط تقدم حي + زر تحديث مثبت + غرفة تحرير متجاوبة + تهيئة ذاتية محصّنة لكل المسارات + **قراءات ذاتية الشفاء**: أي نقطة قراءة (الأخبار/الأقسام/التصدير) تجمع الطبعة داخل الطلب نفسه إن كانت النسخة فارغة أو أقدم من ٣٠ دقيقة — فلا تظهر الجريدة فارغة أبداً مهما كانت نسخة الخادم التي تخدم الطلب على الاستضافة السحابية.

---

## عن الجريدة

«صوت البلاد» واجهة قراءة تحاكي صفحات الجرائد الورقية الرسمية: ورق قديم بألوان دافئة، خطوط عربية زخرفية (أميري ومقرئي وشحرزاد)، مستدع علوي بتاريخ هجري وميلادي ورقم العدد، أعمدة صحفية، وشريط أخبار عاجل هادئ الإيقاع يراعي راحة القارئ. تجمع الجريدة الأخبار من عشرة مصادر وطنية ناطقة بالعربية والفرنسية، وتعرض **العناوين والملخصات القصيرة والروابط فقط** احتراماً لحقوق النشر — فالنص الكامل يبقى في مصدره الأصلي عبر زر «تابع الخبر».

## المميزات

- **واجهة جريدة رسمية** بروح المطبوعات الورقية: مستدع، خطوط مزدوجة، أعمدة، وخبر رئيسي يتوسط الصفحة الأولى.
- **صفحة مستقلة لكل قسم** عبر شريط أقسام ثابت: عاجل، رئاسيات ومناصب، سياسة، اقتصاد، علاقات دولية، مجتمع، رياضة، علوم وتكنولوجيا، ثقافة وفنون.
- **أيقونات SVG أصلية احترافية** لكل قسم وميزة — بلا إيموجيات أو ملصقات.
- **علم الجزائر مرسوماً SVG** بدقة (أخضر وأبيض مع الهلال والنجمة الحمراء) يظهر صحيحاً على كل الأجهزة.
- **تصدير PDF بحجم A4**: زر طباعة بأنماط طباعة مخصصة تحافظ على الصور والخطوط، وتُلحق رابط المصدر الأصلي تحت كل «تابع الخبر».
- **تواريخ مزدوجة** هجرية وميلادية في المستدع، ووقت نشر نسبي لكل خبر.
- **بحث فوري** في العناوين والملخصات، مع فرز (الأحدث / العاجل أولاً / الأقدم) وفلترة لغوية (عربي / فرنسي).
- **وضع قراءة ليلي** مريح يحفظ تفضيلك محلياً.
- **جلب ذاتي فوري مع شريط تقدم حي**: بمجرد فتح الرابط تُجمع أحدث الأخبار تلقائياً بلا أي تدخل، مع شريط تقدم رفيع أعلى الصفحة يعرض النسبة الحقيقية (عدد المصادر المكتملة) قبل عرض العدد.
- **زر تحديث مثبت أعلى الصفحة**: بجانب شريط الأقسام — جلب فوري من الواجهة مباشرة دون فتح غرفة التحرير، مع أيقونة SVG تدور أثناء الجلب.
- **غرفة تحرير متجاوبة كلياً**: إدارة المصادر، جلب فوري، ضبط فاصل التحديث، وتسجيل بوتات تلغرام — بأحجام تناسب كل الشاشات.
- **بوتات تلغرام**: توكنات مشفرة AES-256-GCM، وأوامر `/latest` و `/breaking` للمشتركين.
- **واجهات تصدير**: خلاصة RSS و JSON API للتكامل الخارجي.
- **تصميم متجاوب كلياً**: من شاشة الهاتف إلى الشاشات العريضة، مع ترقيم صفحات وزر عودة للأعلى.

## التقنيات

| الطبقة | التقنية |
|---|---|
| الإطار | Next.js 16 (App Router) + React 19 |
| الواجهة | Tailwind CSS 4 + مكونات shadcn/ui |
| قاعدة البيانات | Prisma ORM + SQLite (تهيئة ذاتية عند أول تشغيل) |
| جمع الأخبار | rss-parser + مصنِّف آلي للأقسام وكشف العاجل عبر بصمات التشابه |
| المهام الدورية | node-cron + مهام سحابية |
| تلغرام | Telegraf مع تشفير التوكنات |

## بنية المشروع

```
├── src/
│   ├── app/                  # الصفحات ومسارات API
│   │   ├── page.tsx          # الصفحة الأولى للجريدة + صفحات الأقسام
│   │   ├── layout.tsx        # التخطيط الجذري (عربي RTL + الخطوط)
│   │   └── api/              # news, categories, sources, fetch, bots, export…
│   ├── components/newspaper/ # مكونات الجريدة (Masthead, Ticker, Cards, Admin…)
│   └── lib/                  # قاعدة البيانات، الجلب، التصنيف، المجدول، تلغرام
├── prisma/schema.prisma      # مخطط قاعدة البيانات
├── docs/API.md               # توثيق واجهات البرمجة
└── public/                   # الأيقونات والشعار
```

## المصادر الافتراضية

تشمل المصادر الوطنية المعرفة مسبقاً عشرة مواقع جزائرية رائدة بالعربية والفرنسية، ويمكن إضافة مصادر RSS جديدة أو إيقافها من **غرفة التحرير** داخل الجريدة دون لمس الكود.

## الحقوق

العناوين والملخصات المعروضة ملك لمصادرها الأصلية، والجريدة مجرد أداة تجميع وقراءة توفر الرابط المباشر لكل خبر.
